# Laboratórios e Ambientes de Estudo

> Todas as ferramentas e ambientes descritos neste módulo devem ser
> utilizados apenas em instâncias próprias, locais ou oficialmente
> disponibilizadas para fins de treinamento. Nunca devem ser usados
> para testar sistemas de terceiros sem autorização explícita.

## OWASP Juice Shop

### O que é

OWASP Juice Shop é uma aplicação web propositalmente vulnerável,
criada para fins educacionais, que simula uma loja online e contém
dezenas de vulnerabilidades baseadas em falhas reais e comuns em
aplicações web.

### Conceitos relacionados

- SQL Injection
- Cross-Site Scripting (XSS)
- Broken Access Control
- Docker

### Uso educacional

Pode ser executado localmente via Docker, permitindo praticar a
identificação de vulnerabilidades do OWASP Top 10 em um ambiente
seguro, isolado e feito especificamente para aprendizado.

## DVWA

### O que é

DVWA (Damn Vulnerable Web Application) é uma aplicação web em PHP/MySQL
propositalmente insegura, criada para que pessoas estudantes e
profissionais de segurança pratiquem técnicas de identificação e
exploração de vulnerabilidades em um ambiente legal e controlado.

### Conceitos relacionados

- SQL Injection
- Broken Authentication
- Security Misconfiguration
- VirtualBox / VMware

### Uso educacional

Permite ajustar o nível de dificuldade das vulnerabilidades (baixo,
médio, alto), o que a torna útil tanto para iniciantes quanto para
quem já tem mais experiência, sempre em ambiente local e isolado.

## PortSwigger Web Security Academy

### O que é

PortSwigger Web Security Academy é uma plataforma online gratuita de
treinamento em segurança de aplicações web, mantida pela empresa
criadora do Burp Suite, com laboratórios práticos organizados por
tipo de vulnerabilidade.

### Conceitos relacionados

- Cross-Site Request Forgery (CSRF)
- Cross-Site Scripting (XSS)
- SQL Injection
- Burp Suite Community

### Uso educacional

Oferece laboratórios guiados, com explicações teóricas antes de cada
prática, sendo uma boa opção para quem quer aprofundar o
entendimento de uma vulnerabilidade específica de forma estruturada.
